## 🍳 Jeu de Cuisine - Combinaison d'Ingrédients

Un jeu interactif et amusant où vous devez combiner les bons ingrédients pour créer des plats délicieux ! 

### ✨ Fonctionnalités

- **🎮 Gameplay Simple**: Glissez-déposez les ingrédients dans la casserole
- **🍽️ 18+ Recettes**: Découvrez diverses recettes de cuisines du monde
- **📊 Système de Points**: Gagnez des points en complétant les recettes
- **📈 Système de Niveaux**: Progressez et débloquez de nouveaux défis
- **✅ Suggestions de Recettes**: Voyez les recettes que vous pouvez préparer
- **💾 Sauvegarde Automatique**: Votre progression est automatiquement sauvegardée
- **🎨 Animations Fluides**: Des animations et transitions agréables
- **📱 Responsive**: Fonctionne sur desktop, tablette et mobile

### 🎯 Comment Jouer

1. **Choisissez vos Ingrédients**: Glissez les ingrédients disponibles dans la casserole
2. **Consultez les Recettes**: Regardez les recettes disponibles sur le panneau de droite
3. **Complétez une Recette**: Une fois que vous avez les bons ingrédients, cliquez sur "Cuire le Plat"
4. **Gagnez des Points**: Chaque recette réussie vous rapporte des points
5. **Progressez**: Débloquez de nouveaux niveaux en créant des plats

### 📦 Installation

1. Clonez le repository:
```bash
git clone https://github.com/itsplay64-tech/Cooking-animation.git
cd Cooking-animation
```

2. Ouvrez `index.html` dans votre navigateur:
```bash
# Sur macOS/Linux
open index.html

# Sur Windows
start index.html

# Ou simplement double-cliquez sur le fichier
```
